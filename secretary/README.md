# เลขาประจำแชท

เลขาช่วยคุย จับประเด็น จำบริบท สรุปการตัดสินใจ และติดตามเรื่องที่ยังค้างของผู้ใช้ในโปรเจกต์นี้ โดยใช้ไฟล์ในเครื่องเป็นความจำต่อเนื่อง

## เริ่มใช้งาน

เปิดแชทโดยใช้โฟลเดอร์ `C:\Users\asus\Documents\GitHub\Intership v.2` เป็น workspace แล้วพิมพ์ เช่น

- `เลขา วันนี้คุยต่อจากเรื่องล่าสุด`
- `เลขา จำเรื่องนี้ไว้: ...`
- `เลขา สรุปว่าเราคุยและตัดสินใจอะไรไปแล้ว`
- `เลขา ตอนนี้มีเรื่องไหนค้างอยู่`
- `เลขา แก้ความจำเรื่อง ... เป็น ...`
- `เลขา ลืมเรื่อง ... และลบออกจากความจำกับประวัติแชท`

แชททั่วไปและการคุยวางแผนใช้บทบาทเลขาได้โดยไม่ต้องเริ่มงานพัฒนาแอป คำสั่งพัฒนาโค้ดยังคงใช้กฎโปรเจกต์ตามปกติ

เปิดบันทึกอัตโนมัติแล้ว ไม่ต้องเรียกชื่อเลขาหรือสั่งจำทุกครั้ง มี Codex heartbeat ชื่อ `เลขาเก็บความจำแชท` (ID: `automation`) ตรวจเก็บข้อความตกหล่นของแชทที่ตั้งค่าทุก 15 นาที และเงียบเมื่อไม่มีข้อมูลใหม่ รอบตรวจนี้ผูกกับแชทปัจจุบัน ไม่ครอบคลุมทุกแชทในบัญชี การทำงานตามรอบขึ้นกับ Codex scheduler และการเข้าถึง workspace ของแอป

## ไฟล์ที่ใช้

- `AGENTS.md`: กฎการทำงานของเลขา
- `memory/CONTEXT.md`: บริบทล่าสุด ความชอบ การตัดสินใจ และเรื่องค้าง
- `memory/conversations/YYYY-MM-DD.md`: ประวัติข้อความตามลำดับ แยกวันตาม `Asia/Bangkok`
- `memory/.gitignore`: ป้องกันความจำและบทสนทนาถูกเพิ่มเข้า Git โดยปกติ

ก่อนตอบ เลขาอ่านบริบทล่าสุดและค้นประวัติเฉพาะเรื่องที่จำเป็น ก่อนจบแต่ละรอบ เลขาบันทึกข้อความที่เห็นและปรับสรุปให้ตรงกับการคุยล่าสุด ประวัติไม่ถูกแทนที่ด้วยสรุป

## ขอบเขตการจำ

นี่คือการตั้งบทบาทและไฟล์ความจำสำหรับเอเจนต์ที่ทำตาม `AGENTS.md` พร้อมรอบตรวจผ่าน Codex automation ไม่ใช่แอปแชทแยกหรือโปรเซสที่ดักทุกข้อความ แชทใหม่ต้องเข้าถึง workspace นี้และอ่านกฎจึงจะใช้ความจำต่อได้

เลขาบันทึกได้เฉพาะข้อความที่เข้าถึงจริงในแชทปัจจุบันหรือประวัติที่ผู้ใช้ส่งให้ ไม่สามารถดึงทุกแชทในบัญชีหรือคืนข้อความที่ถูกตัดออกจากบริบทได้เอง หากข้อมูลขาด เลขาต้องบอกตรง ๆ

เก็บข้อความผู้ใช้และคำตอบที่ส่งจริง พร้อมสรุปผลและพาธไฟล์ที่เกี่ยวข้อง ไม่เก็บความคิดภายใน ข้อความระบบ/developer, raw tool output ทั้งก้อน รหัสผ่าน token cookie connection string ที่มี credential หรือข้อมูลอ่อนไหวที่ไม่จำเป็น หากต้องปกปิดข้อความ ใช้ `[ปกปิดข้อมูลลับ]` และระบุว่ามีการปกปิด

ความจำเป็นไฟล์ข้อความธรรมดา ไม่ได้เข้ารหัส `.gitignore` ไม่ป้องกันการอ่านจากผู้มีสิทธิ์ในเครื่อง การสำรองทั้งโฟลเดอร์ หรือการใช้ `git add -f` ไม่มีการอัปโหลดหรือซิงก์ภายนอกในงานนี้

เมื่อผู้ใช้สั่งลืม ให้ลบข้อมูลเป้าหมายทั้งสรุปและประวัติที่เกี่ยวข้องในโฟลเดอร์นี้ ไม่อ้างว่าสามารถลบประวัติในระบบแชท สำเนาสำรอง หรือไฟล์ที่อยู่นอกขอบเขตได้
